## 🚀 Overview

A modern, responsive, high-performance portfolio showcasing full-stack web development, client projects, custom business automations, and design services for small businesses and enterprises.

### Key Features
- **Performance & SEO Optimized**: Semantic HTML5, structured JSON-LD schema, local SEO setup, and fast-loading assets.
- **Glassmorphism & Neon Design System**: Responsive CSS custom properties, smooth scrolling, interactive animations, and responsive navigation.
- **Lead Generation & Contact Workflow**: Integrated Google Apps Script serverless backend (`google-apps-script/lead-form.gs`) for automated enquiry collection and CRM syncing.
- **Project Showcase**: Showcasing real-world work in CRM dashboards, billing platforms, online payments, business websites, and lead automation.

