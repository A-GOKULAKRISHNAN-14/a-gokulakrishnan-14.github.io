# Image prompts for the portfolio (premium v2)

Make each image with an AI image tool (ChatGPT / DALL·E, Midjourney, Gemini, Ideogram).
Save it with the **exact file name** below, into `assets/images/`.
The site shows it automatically. Until a file is added, its box stays hidden, so nothing looks broken.

**For speed:** export as **.webp**, quality 75, each file **under 200 KB** (https://squoosh.app).

---

## How to get premium results (read once)

1. **Paste the prompt + the style line** (below) together.
2. **Text inside AI images often comes out broken.** Every prompt keeps words to a minimum.
   If a word is spelled wrong, ask the tool: *"same image, fix the text to say ___"* —
   or ask for *"no readable text, use abstract UI shapes instead"*.
3. Make **2–4 versions** and pick the cleanest. Premium = calm, simple, one clear focus.
4. **Midjourney:** add `--ar 16:10 --style raw --v 7` (use `--ar 7:5` for `work-crm`, `--ar 1200:630` for the share image).
   **ChatGPT:** start with *"Create a wide landscape image:"*.

### Style line — add to the END of every prompt

> ultra premium dark tech aesthetic, deep black-navy background (#06070b), soft violet (#8b5cf6) and cyan (#22d3ee) rim light and glow, glassmorphism UI panels with subtle frosted blur, cinematic studio lighting, shallow depth of field, crisp high-detail render, Apple-keynote quality, lots of clean negative space, no brand logos, no watermark, no real company names, no clutter

### Avoid line — add if your tool has a "negative prompt" box

> blurry text, misspelled words, extra fingers, distorted hands, cheap stock-photo look, busy background, neon overload, cartoon, low resolution, watermark, real brand logos
